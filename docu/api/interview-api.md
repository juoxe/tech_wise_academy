# API – Interview

**Status:** implemented in [TWA-8.3](../product_backlog/backlog.md#twa-83--generate-an-interview-set-from-a-job-ad).
The types of the fields are authoritative in the OpenAPI description generated by the backend
([ADR-0002](../adr/0002-backend-stack.md)); this document describes purpose and rules.
This is the first version, built before [ADR-0006](../adr/0006-local-semantic-matching.md) was
written (Ollama, `bge-m3`); it changes with the decisions there, which are still open.

Module: `interview`. Data: [data model](../data_model/interview-data-model.md).

## Rules

- **Profile:** every request needs the header `X-Profile-Id` (UUID), like the training API. It is a
  stopgap until the login exists (TD-17). A set is only visible to its profile; the set of another
  profile answers `404`.
- **Local only:** the ad goes to the configured embedding service (`EMBEDDING_URL`) and nowhere else
  ([ADR-0006](../adr/0006-local-semantic-matching.md)).
- **Duration:** the first `POST` also embeds all tools and can take minutes; later ones take seconds.
- **Versioning:** as in the [learning content API](learning-content-api.md).

## Endpoints

| Method | Path | Purpose | Success | Errors |
|--------|------|---------|---------|--------|
| POST | `/api/interview-sets` | Generate a set from `{ job_ad }` (50 to 20,000 characters) | `201` set | `422` text too short, too long or without sentences, `503` embedding service not reachable (nothing is stored) |
| GET | `/api/interview-sets` | The sets of the profile, newest first | `200` list of summaries | – |
| GET | `/api/interview-sets/{id}` | One set with its cards | `200` set | `404` |
| DELETE | `/api/interview-sets/{id}` | Delete a set with its text and values | `204` | `404` |

## Summary

| Field | Description |
|-------|-------------|
| id | ID of the set |
| title | The first line of the ad |
| created_at | Time of creation |
| card_count | Number of cards |

## Set

| Field | Description |
|-------|-------------|
| id, title, created_at | As in the summary |
| embedding_model | The model of the similarity values |
| cards | The cards in their order: the tools the ad names first, then the most similar ones |

## Card

| Field | Description |
|-------|-------------|
| tool_key | Key of the tool; name and texts come from the [tool API](learning-content-api.md) |
| similarity | Cosine similarity to the closest sentence of the ad; about 0.3 (unrelated) to 0.8 (close) |
| mentioned | The ad names the tool |
| evidence | The sentence of the ad behind the card |

The API returns only the cards. The similarity values of the other tools stay in the database.

# API – Learning Content (draft)

**Status:** draft for [TWA-4.3](../product_backlog/backlog.md#twa-43--backend-skeleton-and-tool-api).
It describes the planned read access to the tools. The types of the fields are authoritative in
the OpenAPI description generated by the backend ([ADR-0002](../adr/0002-backend-stack.md)); this
document describes purpose and rules.

Module: `learning_content`. Data: [data model](../data_model/learning-content-data-model.md).

## Rules

- **Versioning** ([ADR-0001](../adr/0001-architecture-concept.md)): no version in the path;
  changes are compatible; a path version (`/api/v1/...`) is introduced when external clients appear.
- **Read only:** creating and editing tools needs roles and sign-in (TD-17) and is not part of the
  first slice.
- **Language:** the optional query parameter `lang` selects the language of the texts (summary
  and hints). It defaults to `de`; in the first slice only German exists. Each response says in
  `language` which language the texts are in. English follows in MS 3 with the same parameter.
- Hints and examples are returned in the order of their `position`.
- Alternatives are returned from both sides of a pair, sorted by name.

## Endpoints

| Method | Path | Purpose | Success | Errors |
|--------|------|---------|---------|--------|
| GET | `/api/tools?lang=de` | List all tools | `200` list of tool summaries | `422` unknown language |
| GET | `/api/tools/{key}?lang=de` | Get one tool with hints, examples and alternatives | `200` tool | `404` unknown key, `422` unknown language |

The list is not paginated while it holds few tools; pagination is added when it grows. The
frontend of the first slice uses only the list; the detail endpoint is available for later use.

## Tool Summary (list)

| Field | Description |
|-------|-------------|
| key | Readable short name |
| name | Display name |
| category | Category code: `DEVOPS`, `BACKEND`, `FRONTEND`, `SECURITY` or `AI_DATA`; for the programming languages `OBJECT_ORIENTED`, `FUNCTIONAL`, `PROCEDURAL`, `DECLARATIVE` or `MULTI_PARADIGM` |
| level | Level of the tool: `1` (know), `2` (intermediate) or `3` (expert), see [Level](../data_model/learning-content-data-model.md#level) |
| summary | One sentence: what is it? (in the selected language) |
| language | Language of the returned texts |
| icon | Icon identifier; empty if the tool has none |

## Tool (detail)

All fields of the summary and:

| Field | Description |
|-------|-------------|
| documentation_url | Link to the official documentation |
| hints | List of hint texts in order (in the selected language) |
| examples | List of code examples in order |
| alternatives | List of `{ key, name }` of the alternative tools |

This folder holds the architecture and technology decisions of Tech Wise Academy. Each ADR compares
the options in a decision matrix and records the outcome per topic.

- [open-decisions.md](open-decisions.md) – what is still to be decided (the next one first) and the
  record of the decisions that have been made.
- [0000-template.md](0000-template.md) – template for a new ADR.
- The process for making decisions is described in the workflow skill
  (`.claude/skills/workflow/SKILL.md`).
